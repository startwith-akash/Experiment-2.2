### **Title**  
To create a Dynamic Product Filter using front-end technologies.

---

### **Approach**

In this experiment, a Dynamic Product Filter was designed and implemented to display products based on the user’s dropdown selection. The objective was to understand data filtering and dynamic UI updates.

* Product data was stored in an array for easy manipulation.  
* A dropdown menu was used to select product categories.  
* JavaScript/React was used to filter and display products dynamically.  
* CSS Grid was applied to create a responsive layout for product cards.  

This approach helps in understanding array manipulation, state management, and responsive layout design.

---

### **Learning Outcomes**

* Understood how to filter data dynamically using arrays.  
* Learned to handle dropdown-based user input.  
* Gained experience in creating responsive layouts using CSS Grid.  
* Improved knowledge of dynamic UI rendering using JavaScript/React.
